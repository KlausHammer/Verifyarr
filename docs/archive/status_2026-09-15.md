## 2. Fixes (all in the worktree, uncommitted)

- **0001 – P0 None-anchor fix + hermetic full-track cache priming in tests.**
  A crash in `_resync_verified` when anchors are `None` (now filtered); the test reads the
  per-video transcript cache, so the resync comparison never lacks evidence.
- **0002 – VAD timeline traffic control** (`verifyarr/vad.py`, settings, wiring, tests):
  steers where to transcribe based on speech time instead of stop-word lists —
  language-neutral and cheap. Tests: 24+22 green.
- **0003 – Sync tests via a primed full-track cache + the VAD binary in the Dockerfile.**
- **0004 – Straddler fix in `anchor_regions`** (`verifyarr/subtitles.py` + 3 tests in
  `tests/test_sync_verification.py`): a thin anchor between two DISAGREEING neighbours, whose
  value lies strictly between them (a clip that covers a block boundary), is dropped instead
  of vetoing the whole plan. The dense re-measurement before writing is
  unchanged. A test that locked in the old behaviour was updated to the intended
  change; two new tests keep the veto for the still-dangerous cases (a wild value
  outside both neighbours; drift). Suite: 26 passed + 22 subtests.

## 3. Discoveries (measured, not guessed)

The offset test (8 healthy episodes × piecewise/drift/hole, seeded `offset-v1`, no new
Whisper — corruption on the SRT + fixture transcriptions):

- **Hole (5 min deleted): 8/8 perfect.** 100 % of surviving lines ≤1 s. Good lines are
  not touched.
- **Drift (2 % progressive, fps type): 8/8 found, but loose.** p50 ~1.0 s, ~47 % ≤1 s,
  ~80 % ≤2 s. Fixed roughly, stays ~1 s too loose.
- **Piecewise (6 blocks ±5–15 s): at first 5/8, all 3 failures honestly flagged SUSPECT**
  (no silent failures). Root cause: one boundary-straddling anchor per block boundary triggered
  the thin-region veto and discarded 55 clean anchors — alass' wrong block fit won,
  because the content score cannot see time (both "ok" on words, both wrong on time).
  After fix 0004: **7/8 good** (p50 ≤0.5 s, 79–92 % ≤1 s). C_S03E09 only partially
  (p50 7.1→1.5 s): dense neighbouring blocks (+8.1/+5.3 s) are over-segmented into 8 regions, and
  the verification is blind at ~1–2 s. The other 21 runs byte-identical: no
  regression. Before-data: `e2e_offset_before_fix.jsonl`.
- Conclusion on the user's hypothesis: the Whisper timestamps contained the answer all along —
  more transcriptions were not what was missing, the veto rule was the fault.
